# 008. 理解循环控制语句（break, continue）
## **循环控制语句**
C语言提供了几种循环控制语句，用于在循环中进行更精细的控制。

- **`break`**：立即终止循环。

- **`continue`**：跳过当前循环的剩余部分，直接进入下一次迭代。

#### 示例1：使用`break`终止循环

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            break; // 当i等于5时，终止循环
        }
        printf("%d\n", i);
    }
    return 0;
}
```
#### 示例2：使用`continue`跳过当前迭代

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            continue; // 当i为偶数时，跳过当前迭代
        }
        printf("%d\n", i);
    }
    return 0;
}
```
