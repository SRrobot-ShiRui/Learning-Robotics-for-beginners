# 001. 编写一个简单的Hello World程序
```c
#include <stdio.h> // 引入标准输入输出头文件

int main() // 主函数
{
    printf("Hello World!\n"); // 输出字符串 "Hello World!"，\n 表示换行
    return 0; // 程序正常结束，返回值为0
}
```

### 编译和运行步骤：

1. **保存代码**：将上述代码保存为一个文件，例如 `hello.c`。

2. **编译代码**：

- 如果你使用的是Windows系统，可以使用Visual Studio等开发工具，或者使用命令行工具（如MinGW）。

- 在命令行中，运行以下命令进行编译：

```bash
gcc hello.c -o hello
```

这会生成一个可执行文件 `hello.exe`（Windows）或 `hello`（Linux/Mac）。

3. **运行程序**：

- 在命令行中运行：

```bash
hello
```

- 程序会输出：
`Hello World!`
