# 003. 声明不同数据类型的变量并赋值
## **变量声明**

变量是程序中用于存储数据的容器。在C语言中，变量必须先声明，然后才能使用。

**基本数据类型**：

- `int`：整数类型。

- `float`：单精度浮点数。

- `double`：双精度浮点数。

- `char`：字符类型。

- `void`：无类型。

**变量声明示例**：

```c
int a = 10; // 声明一个整数变量a，并初始化为10
float b = 3.14; // 声明一个浮点数变量b，并初始化为3.14
char c = 'A'; // 声明一个字符变量c，并初始化为字符'A'
```
