# C语言中的基本数据类型

C语言提供了几种基本数据类型，用于声明不同类型的变量。

## 1. 整型（int）
用于存储整数，通常包括正数、负数和零。
```c
int age = 25; // 声明一个整型变量age并初始化为25
```

## 2. 浮点型（float 和 double）
- `float`：单精度浮点数，用于存储小数。
- `double`：双精度浮点数，比float有更高的精度。
```c
float price = 99.99f; // 声明一个浮点型变量price并初始化，注意f后缀表示float
double salary = 3000.00; // 声明一个双精度浮点型变量salary
```

## 3. 字符型（char）
用于存储单个字符。
```c
char letter = 'A'; // 声明一个字符型变量letter并初始化为大写字母A
```

## 常量和变量

## 常量（Constants）
常量是固定值，在程序执行过程中不会改变。
```c
#define PI 3.14159 // 预处理指令定义常量PI
const int MAX_SIZE = 100; // 声明一个只读的整型常量MAX_SIZE
```

## 变量（Variables）
变量是程序运行时可以改变值的量。
```c
int count = 10; // 声明一个整型变量count并初始化为10
```
