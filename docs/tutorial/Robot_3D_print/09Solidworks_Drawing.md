# 工程图创建与视图布局
## 工程图概念、作用及创建工程图的方法

### 工程图概念
 **定义**：工程图（Drawing）是将三维模型转换为二维图纸的过程，用于详细描述产品的设计、尺寸、公差和材料等信息。工程图是制造、装配和检验产品的重要依据。
### 工程图作用

- **详细描述**：提供产品的详细尺寸、公差、材料和表面处理等信息。

- **制造依据**：用于指导生产制造过程，确保产品的一致性和质量。

- **装配指导**：提供装配图，指导产品的组装过程。

- **检验标准**：用于质量检验，确保产品符合设计要求。

- **技术交流**：用于与客户、供应商和内部团队进行技术交流。
### 创建工程图的方法

**从三维模型生成工程图**：

- 打开三维模型文件。

- 选择“插入”菜单，然后选择“工程图”。

- 选择合适的图纸格式和尺寸，点击“确定”。

- 在工程图中，选择“视图”菜单，然后选择“标准三视图”（主视图、俯视图、左视图）。

**生成基本视图**：

- **主视图**：默认生成的视图，通常显示模型的正面。

- **俯视图**：显示模型的顶部视图。

- **左视图**：显示模型的左侧视图。

- **右视图**：显示模型的右侧视图。

- **后视图**：显示模型的背面视图。

- **底视图**：显示模型的底部视图。

**使用投影视图**：

- 从一个已有的视图生成新的视图，保持与原视图的投影关系。

- 选择已有的视图，右键点击选择“投影视图”，选择投影方向，生成新的视图。

**使用辅助视图**：

- 用于显示模型的特定角度，通常用于复杂形状的表达。

- 选择已有的视图，右键点击选择“辅助视图”，选择投影方向和角度，生成新的视图。

**使用局部视图**：

- 用于放大显示模型的局部区域，提供更详细的视图。

- 选择已有的视图，右键点击选择“局部视图”，选择局部区域，生成新的视图。

## 工程图模板的使用与自定义

### 工程图模板的使用

1. **选择模板**：

	- 打开SolidWorks，选择“文件” > “新建” > “工程图”。
	
	- 在“新建SolidWorks文件”对话框中，选择合适的模板文件（通常为`.slddrt`格式）。

2. **设置图纸格式**：

	- 在工程图中，选择“视图”菜单，然后选择“图纸格式”。
	
	- 选择合适的图纸格式和尺寸，点击“确定”。

### 自定义工程图模板

**自定义标题栏**：

- 选择“视图”菜单，然后选择“标题栏”。

- 在标题栏中，可以添加或修改公司名称、项目名称、图纸编号等信息。

**自定义图框**：

- 选择“视图”菜单，然后选择“图框”。

- 在图框中，可以添加或修改图框的尺寸、边框、标题栏等信息。

**设置图纸格式**：

- 选择“视图”菜单，然后选择“图纸格式”。

- 在图纸格式中，可以设置图纸的尺寸、边距、标题栏、图框等信息。

**保存自定义模板**：

- 完成自定义后，选择“文件” > “保存”。

- 保存为`.slddrt`格式的模板文件，以便下次使用。
