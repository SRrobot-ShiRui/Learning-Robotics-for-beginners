# 基础特征建模

### 拉伸（Extrude）、旋转拉伸（Revolve）、放样（Loft）等基础特征建模命令的原理与操作方法

#### 拉伸（Extrude）

**原理**：拉伸命令用于将二维草图沿着指定方向拉伸成三维实体。拉伸方向可以是垂直于草图平面，也可以是沿着指定的路径。

**操作方法**：

1. 进入草图绘制状态，绘制需要拉伸的二维草图。

2. 选择“拉伸”命令（通常在特征工具栏中）。

3. 在属性管理器中设置拉伸参数：

	- **方向**：选择拉伸方向，可以是“双向”、“单向”或“到顶点”等。
		
	- **深度**：输入拉伸的深度值。
		
	- **方向1**和**方向2**：如果选择“双向”，可以分别设置两个方向的深度。
	
4. 点击“确定”按钮，完成拉伸操作。


#### 旋转拉伸（Revolve）

**原理**：旋转拉伸命令用于将二维草图绕指定轴旋转生成三维实体。旋转轴可以是草图中的直线或外部轴。

**操作方法**：

1. 进入草图绘制状态，绘制需要旋转的二维草图。

2. 选择“旋转拉伸”命令（通常在特征工具栏中）。

3. 在属性管理器中设置旋转拉伸参数：

	- **旋转轴**：选择旋转轴，可以是草图中的直线或外部轴。
		
	- **角度**：输入旋转的角度值，通常为360度生成完整实体。
	
4. 点击“确定”按钮，完成旋转拉伸操作。


#### 放样（Loft）

**原理**：放样命令用于通过多个二维草图生成复杂的三维实体。这些草图可以是不同形状，放样命令会在这些草图之间生成平滑的过渡面。

**操作方法**：

1. 进入草图绘制状态，绘制多个需要放样的二维草图。每个草图可以是不同的形状，但必须在不同的平面上。

2. 选择“放样”命令（通常在特征工具栏中）。

3. 在属性管理器中设置放样参数：

	- **轮廓**：选择所有参与放样的草图。
		
	- **引导线**：如果需要，可以添加引导线来控制放样的形状。
		
	- **对齐方式**：选择草图之间的对齐方式，如“起点对齐”、“终点对齐”等。
	
4. 点击“确定”按钮，完成放样操作。


### 利用草图创建简单的三维实体模型

#### 拉伸一个矩形草图生成长方体

**进入草图绘制状态**：

- 点击工具栏中的“草图”按钮。

**绘制矩形草图**：

- 选择“矩形”工具，绘制一个矩形。

**添加尺寸约束**：

- 选择矩形的边，添加长度和宽度尺寸。

**拉伸草图**：

- 选择“拉伸”命令。

- 在属性管理器中设置拉伸参数：

	- **方向**：选择“单向”。
		
	- **深度**：输入拉伸的深度值，例如50mm。
	
- 点击“确定”按钮，生成长方体。


#### 旋转圆形草图生成圆柱体

**进入草图绘制状态**：

- 点击工具栏中的“草图”按钮。

**绘制圆形草图**：

- 选择“圆”工具，绘制一个圆。

**添加尺寸约束**：

- 选择圆，添加半径尺寸，例如25mm。

**旋转拉伸草图**：

- 选择“旋转拉伸”命令。

- 在属性管理器中设置旋转拉伸参数：

	- **旋转轴**：选择圆的中心点或草图中的任意直线作为旋转轴。
		
	- **角度**：输入旋转的角度值，通常为360度。
	
- 点击“确定”按钮，生成圆柱体。


### 特征编辑与修改技巧

#### 修改特征尺寸

- **通过属性管理器**：

1. 在特征管理器中，选择需要修改的特征。

2. 双击特征，打开属性管理器。

3. 在属性管理器中，修改尺寸参数。

4. 点击“确定”按钮，完成修改。


#### 修改特征草图

**通过特征管理器**：

1. 在特征管理器中，选择需要修改的特征。

2. 右键点击特征，选择“编辑草图”。

3. 在草图绘制状态下，修改草图的形状和尺寸。

4. 退出草图绘制状态，特征会自动更新。


#### 修改特征顺序

**通过特征管理器**：

1. 在特征管理器中，选择需要调整顺序的特征。

2. 按住特征，拖动到新的位置。

3. 释放鼠标，特征顺序会自动更新，模型也会重新生成。


#### 特征树的概念

**特征树**：特征树是模型的特征列表，以树状结构显示。每个节点代表一个特征，包括草图、拉伸、旋转拉伸、放样等。

**管理与编辑模型特征**：

- **选择特征**：在特征树中选择特征，可以高亮显示模型中的对应部分。

- **编辑特征**：右键点击特征，选择“编辑特征”或“编辑草图”进行修改。

- **删除特征**：右键点击特征，选择“删除”删除特征。

- **隐藏/显示特征**：右键点击特征，选择“隐藏”或“显示”控制特征的显示状态。

- **特征顺序**：通过拖动特征节点，调整特征的生成顺序。
