# Solidworks软件简介

## SolidWorks的发展历程、主要功能模块及在机械设计领域的应用现状

### 发展历程

- **1993年**：SolidWorks公司成立，由PTC公司的技术副总裁与CV公司的副总裁发起，总部位于马萨诸塞州的康克尔。

- **1995年11月**：SolidWorks第一套三维机械设计软件研制成功。

- **1997年**：被法国达索公司以三亿一千万美元的高额市值全资并购。并购后的SolidWorks以原来的品牌和管理技术队伍继续独立运作，成为CAD行业一家高素质的专业化公司。
### 主要功能模块

- **SOLIDWORKS**：主要的CAD软件模块，用于三维建模、装配体设计和工程图纸。

- **SOLIDWORKS Flow Simulation**：流体动力学仿真工具，用于模拟和分析流体流动和热传递。

- **SOLIDWORKS Plastics**：用于塑料注塑成型仿真，帮助设计人员优化塑料部件和模具。

- **SOLIDWORKS Electrical**：电气设计工具，包括原理图和电气系统建模。

- **SOLIDWORKS Composer**：用于创建产品文档、技术插图和交互式动画的工具。

- **SOLIDWORKS Visualize**：高质量渲染和动画工具，用于创建逼真的产品可视化。

- **SOLIDWORKS CAM**：计算机辅助制造工具，用于生成CNC加工路径。

- **SOLIDWORKS Simulation**：有限元分析（FEA）工具，用于结构分析、热分析和其他物理模拟。

- **SOLIDWORKS Motion**：用于运动学和动力学分析，模拟装配体的运动行为。
### 在机械设计领域的应用现状

- **广泛应用**：SolidWorks已成为全球装机量最大、最好用的软件之一，广泛应用于航空航天、机车、食品、机械、国防、交通、模具、电子通讯、医疗器械、娱乐工业、日用品/消费品、离散制造等分布于全球100多个国家的约3万1千家企业。

- **教育市场**：每年来自全球4300所教育机构的近145000名学生通过SolidWorks的培训课程。

- **中国市场**：在中国市场，SolidWorks具有较高的市场占有率和知名度，其强大的功能、丰富的模块和广泛的应用领域，使其成为设计和工程领域首选的软件之一。应用领域涵盖机械、汽车、航空航天、电子、医疗器械等多个行业。

## SolidWorks的安装与卸载步骤

### 安装步骤
1. **下载安包**：从官方或授权经销商处下载SolidWorks安装包。
2. **运行安装程序**：双击安装包，启动安装程序。
3. **选择安装路径**：选择合适的安装路径，通常默认路径为`C:\Program Files\SolidWorks Corp`。
4. **选择安装模块**：

	- **SOLIDWORKS**：主要的CAD软件模块，必须安装。
	
	- **SOLIDWORKS Flow Simulation**：流体动力学仿真工具，机械设计常用。
	
	- **SOLIDWORKS Plastics**：塑料注塑成型仿真工具，按需选择。
	
	- **SOLIDWORKS Electrical**：电气设计工具，按需选择。
	
	- **SOLIDWORKS Composer**：创建产品文档、技术插图和交互式动画的工具，按需选择。
	
	- **SOLIDWORKS Visualize**：高质量渲染和动画工具，按需选择。
	
	- **SOLIDWORKS CAM**：计算机辅助制造工具，按需选择。

1. **接受许可协议**：阅读并接受软件许可协议。
2. **安装**：点击“安装”按钮，等待安装完成。
3. **激活**：安装完成后，根据提示进行软件激活。
### 卸载步骤
1. **卸载主程序**：
	- 打开“控制面板”。
	
	- 选择“程序和功能”。
	
	- 找到并选择“SolidWorks”，点击“卸载”按钮，按照提示完成卸载。

2. **删除注册表项**：

	- 按`Win + R`键，输入`regedit`，打开注册表编辑器。
	
	- 导航到`HKEY_CURRENT_USER\Software\`和`HKEY_LOCAL_MACHINE\SOFTWARE\`路径。
	
	- 找到并删除带有`SolidWorks`字样的文件夹。
	
	- 使用`Ctrl + F`搜索，确保没有残留的注册表项。

3. **删除残余文件**：

	- 删除以下路径中的所有相关文件夹：
	
	- `C:\Documents and Settings\【登录用户名】\Application Data\【所有相关SolidWorks的文件夹】`
	
	- `C:\Documents and Settings\【登录用户名】\Local Settings\Application Data\【所有相关SolidWorks的文件夹】`
	
	- `C:\SolidWorks Data`（如果是toolbox文件且有定制内容，请不要删除，安装时根据选项使用现有数据）
	
	- `C:\Documents and Settings\Administrator\Local Settings\Temp`（清空该目录）
	
	- `X:\Program Files\SolidWorks Corp`（X为安装SolidWorks所在的盘符）
	
	- 在C盘搜索是否还有与SolidWorks相关的文件，如有，进行删除。

完成以上步骤后，即可完全卸载SolidWorks并删除所有残留文件和注册表项。
