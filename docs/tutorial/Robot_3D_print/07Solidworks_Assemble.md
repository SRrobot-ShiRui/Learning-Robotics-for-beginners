# 装配体创建与组件添加

## 装配体的概念、类型及创建装配体的方法

### 装配体的概念
**定义**：装配体是由多个零部件组合生成的复杂体，其扩展名为 `.sldasm`。装配体的零部件可以包括独立的零件和其他装配体（称为子装配体）。
### 装配体的类型
- **自底向上装配**：先创建装配体的零部件，然后将它们以组件的形式添加到装配文件中。这种装配设计方法是先创建最下层的子装配件，再把各子装配件或部件装配成更高级的装配部件，直到完成装配任务为止。

- **自顶向下装配**：在装配部件的上下文中设计，上下文设计指在装配中参照其他零部件对当前工作部件进行设计，即在装配部件的顶级向下产生子装配和零件的装配方法。
### 创建装配体的方法
**自底向上装配**：

1. 创建所有需要的零件模型。
2. 打开一个新的装配体文件（`.sldasm`）。
3. 使用“添加组件”命令，将零件模型添加到装配体中。
4. 使用“配合”功能约束组件间的相对位置与运动关系。

**自顶向下装配**：

1. 创建一个新的装配体文件（`.sldasm`）。
2. 在装配体中直接创建或插入一个基础组件。
3. 参照基础组件设计其他零件，这些零件可以直接在装配体中创建。
4. 使用“配合”功能约束组件间的相对位置与运动关系。

## 将零件模型添加到装配体中及基本操作

### 添加零件模型到装配体

**步骤**：

1. 打开装配体文件。
2. 选择“添加组件”命令。
3. 选择需要添加的零件文件。
4. 定位方式有“绝对原点”、“选择原点”、“通过约束”和“移动”。
### 组件的基本操作

- **重命名**：在特征管理器中，右键点击组件，选择“重命名”。

- **移动**：选择组件，使用“移动”命令，可以动态移动组件或创建约束来定位组件。

- **旋转**：选择组件，使用“旋转”命令，可以围绕指定轴旋转组件。
### 使用“配合”功能

**配合类型**：

- **同心**：用于圆形或圆弧边线之间的配合。

- **平行**：用于直线、平面之间的配合。

- **垂直**：用于直线、平面之间的配合。

- **距离**：用于定义两个实体之间的距离。

**操作步骤**：

1. 选择需要配合的两个组件。
2. 选择“配合”命令。
3. 选择合适的配合类型，如“同心”、“平行”、“垂直”或“距离”。
4. 输入具体的配合参数，如距离值。
5. 点击“确定”完成配合。

## 装配一个螺栓连接结构

### 装配体创建与组件添加的基本流程与技巧

1. **创建装配体文件**：打开SolidWorks，选择“文件” > “新建” > “装配体”。
2. **添加基础组件**：使用“添加组件”命令，将第一个零件（如螺栓孔所在的板）添加到装配体中。
3. **添加其他组件**：继续使用“添加组件”命令，将螺栓、螺母等其他零件添加到装配体中。
4. **使用配合功能**：

	- 选择螺栓和螺栓孔所在的板，使用“同心”配合，确保螺栓与孔同心。
	
	- 选择螺栓和螺母，使用“平行”和“距离”配合，确保螺母与螺栓平行且有适当的预紧力。

5. **检查和调整**：

	- 检查所有组件的配合关系，确保装配体的正确性和稳定性。
	
	- 如果需要，可以使用“移动”和“旋转”命令调整组件的位置和方向。
