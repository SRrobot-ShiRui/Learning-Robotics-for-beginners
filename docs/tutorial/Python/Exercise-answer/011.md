# 011. 定义一个字符串变量并打印其长度
在 Python 中，可以使用 `len()` 函数来获取字符串的长度。以下是如何定义一个字符串变量并打印其长度的示例代码：

## 示例代码

```python
# 定义一个字符串变量
my_string = "Hello, World!"

# 使用 len() 函数获取字符串的长度
string_length = len(my_string)

# 打印字符串的长度
print("字符串的长度是：", string_length)
```
### 运行结果
运行上述代码后，输出如下：

`字符串的长度是： 13`
### 代码解释

1. **定义字符串变量**：使用 `my_string = "Hello, World!"` 定义了一个字符串变量 `my_string`，并赋值为 `"Hello, World!"`。
2. **获取字符串长度**：使用 `len(my_string)` 获取字符串的长度。`len()` 函数返回字符串中字符的数量，包括空格和标点符号。
3. **打印长度**：使用 `print()` 函数将字符串的长度输出到控制台。

## 扩展：动态输入字符串
如果需要从用户那里动态获取字符串，可以使用 `input()` 函数：

```python
# 从用户输入获取字符串
user_string = input("请输入一个字符串：")

# 获取字符串的长度
string_length = len(user_string)

# 打印字符串的长度
print("您输入的字符串长度是：", string_length)
```
### 示例运行
假设用户输入 `"Python is fun!"`，运行结果如下：

```
请输入一个字符串：Python is fun!
您输入的字符串长度是： 15
```
