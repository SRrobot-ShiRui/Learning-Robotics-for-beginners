# 001. 写出python的版本号
在 Python 中，可以通过以下代码获取当前 Python 解释器的版本号：

```python
import sys
print(sys.version)
```

运行这段代码后，会输出类似以下内容：

```
3.12.6 (default, Sep  6 2024, 05:47:02) 
[GCC 10.3.0]
```

其中 `3.12.6` 是 Python 的主版本号、次版本号和修订号。如果你只需要获取版本号（如 `3.12.6`），可以使用以下代码：

```python
import sys
print(sys.version.split()[0])
```

这会输出更简洁的版本号，例如 `3.12.6`。
